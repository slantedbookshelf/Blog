### 1、<a href="https://leetcode.cn/problems/two-sum/" target="_blank" rel="noopener noreferrer">两数之和</a> <span class="difficulty-badge difficulty-badge--easy">简单</span>

给定整数数组 nums 和目标值 target，找出和为 target 的两个数的下标。
输入：nums = [2,7,11,15], target = 9
输出：[0,1]

**思路**：用 HashMap 记录已遍历数字和下标，遍历时查找 target - nums[i] 是否存在。

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];
            if (map.containsKey(need)) {
                return new int[]{map.get(need), i};
            }
            map.put(nums[i], i);
        }
        return new int[0];
    }
}
```

### 49、<a href="https://leetcode.cn/problems/group-anagrams/" target="_blank" rel="noopener noreferrer">字母异位词分组</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定字符串数组 strs，把字母异位词分到同一组。
输入：strs = ["eat","tea","tan","ate","nat","bat"]
输出：[["eat","tea","ate"],["tan","nat"],["bat"]]

**思路**：把每个字符串排序后作为 key，用 HashMap 收集同组字符串。

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            char[] chars = s.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```

### 128、<a href="https://leetcode.cn/problems/longest-consecutive-sequence/" target="_blank" rel="noopener noreferrer">最长连续序列</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。时间复杂度要求O(n)
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4

**思路**：把所有数放进 Set，只从"没有前驱（num-1 不存在）"的起点出发，往后数连续长度，取最大值。

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        int res = 0;
        for (int num : nums) {
            set.add(num);
        }
        for (int num : set) {
            if (set.contains(num - 1)) {
                continue;
            }
            int n = 1;
            while (set.contains(num + 1)) {
                n++;
                num++;
            }
            res =Math.max(res,n);
        }
        return res;
    }
}
```

```java
    public void moveZeroes(int[] nums) {
        int idx = 0;
        for (int num : nums) {
            if (num != 0) nums[idx++] = num;
        }
        while (idx < nums.length) nums[idx++] = 0;
    }
}
```

### 11、<a href="https://leetcode.cn/problems/container-with-most-water/" target="_blank" rel="noopener noreferrer">盛最多水的容器</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定高度数组 height，找出两条线能盛最多水的面积。
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49

**思路**：左右双指针计算面积，每次移动较短的一边。

```java
class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1, ans = 0;
        while (l < r) {
            ans = Math.max(ans, (r - l) * Math.min(height[l], height[r]));
            if (height[l] < height[r]) l++; else r--;
        }
        return ans;
    }
}
```

### 15、<a href="https://leetcode.cn/problems/3sum/" target="_blank" rel="noopener noreferrer">三数之和</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定整数数组 nums，找出所有和为 0 且不重复的三元组。
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]

**思路**：排序后枚举第一个数，再用左右指针找两数和并跳过重复值。

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> ans = new ArrayList<>();
        for (int i = 0; i < nums.length - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            int l = i + 1, r = nums.length - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum == 0) {
                    ans.add(Arrays.asList(nums[i], nums[l], nums[r]));
                    while (l < r && nums[l] == nums[l + 1]) l++;
                    while (l < r && nums[r] == nums[r - 1]) r--;
                    l++; r--;
                } else if (sum < 0) l++; else r--;
            }
        }
        return ans;
    }
}
```

给定柱子高度数组 height，计算下雨后最多能接多少水。
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6

**思路**：双指针维护左右最大高度，每次结算较低侧能接的水。

```java
class Solution {
    public int trap(int[] height) {
        int l = 0, r = height.length - 1, lm = 0, rm = 0, ans = 0;
        while (l < r) {
            lm = Math.max(lm, height[l]);
            rm = Math.max(rm, height[r]);
            if (lm < rm) ans += lm - height[l++]; else ans += rm - height[r--];
        }
        return ans;
    }
}
```

### 3、<a href="https://leetcode.cn/problems/longest-substring-without-repeating-characters/" target="_blank" rel="noopener noreferrer">无重复字符的最长子串</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定字符串 s，找出不含重复字符的最长子串长度。
输入：s = "abcabcbb"
输出：3
解释：最长无重复子串是 "abc"。

**思路**：滑动窗口配合字符最近位置，遇到重复字符就移动左边界。

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int res=0;
        Set<Character> set= new HashSet<>();
        char[] arr = s.toCharArray();
        int l=0;
        for(int r=0;r<s.length();++r){
            while(set.contains(arr[r])){
                set.remove(arr[l]);
                l++;
            }
            set.add(arr[r]);
            res = Math.max(res,r-l+1);
        }
        return res;
    }
}
```

### 438、<a href="https://leetcode.cn/problems/find-all-anagrams-in-a-string/" target="_blank" rel="noopener noreferrer">找到字符串中所有字母异位词</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定字符串 s 和 p，找出 s 中所有 p 的异位词子串起始下标。
输入：s = "cbaebabacd", p = "abc"
输出：[0,6]

**思路**：维护长度为 p.length 的窗口计数，与 p 的计数相等时记录左端点。

```java
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        int n=s.length(),m=p.length();
        List<Integer> res = new ArrayList<>();
        int[] s_arr = new int[26];
        int[] p_arr = new int[26];
        if(n<m) return res;
        for(int i=0;i<m;++i){
            p_arr[p.charAt(i)-'a']++;
            s_arr[s.charAt(i)-'a']++;
        }
        for(int i=0;i<n-m+1;++i){
            if(i!=0){
                s_arr[s.charAt(i-1)-'a']--;
                s_arr[s.charAt(m+i-1)-'a']++;
            }
            if(Arrays.equals(s_arr,p_arr)){
                res.add(i);
            }
        }
        return res;
    }
}
```

### 239、<a href="https://leetcode.cn/problems/sliding-window-maximum/" target="_blank" rel="noopener noreferrer">滑动窗口最大值</a> <span class="difficulty-badge difficulty-badge--hard">困难</span>

给定数组 nums 和窗口大小 k，返回每个滑动窗口中的最大值。
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]

**思路**：用单调递减队列保存下标，队头始终是当前窗口最大值。

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        Deque<Integer> que = new LinkedList<>();
        int[] res = new int[nums.length-k+1];
        for(int i=0;i<nums.length;++i){
            if(i>=k&&nums[i-k]==que.peekFirst()){
                que.removeFirst();
            }
            while(!que.isEmpty()&&nums[i]>que.peekLast()){
                que.removeLast();
            }
            que.offer(nums[i]);
            if(i>=k-1){
                res[i-k+1]=que.peekFirst();
            }
        }
        return res;
    }
}
```

### 76、<a href="https://leetcode.cn/problems/minimum-window-substring/" target="_blank" rel="noopener noreferrer">最小覆盖子串</a> <span class="difficulty-badge difficulty-badge--hard">困难</span>

给定字符串 s 和 t，找出 s 中覆盖 t 所有字符的最短子串。
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"

**思路**：滑动窗口维护字符需求，满足覆盖后不断收缩左边界更新答案。

```java
class Solution {
    public String minWindow(String s, String t) {
        int[] need = new int[128];
        for (char c : t.toCharArray()) need[c]++;
        int left = 0, count = t.length(), start = 0, min = Integer.MAX_VALUE;
        for (int right = 0; right < s.length(); right++) {
            if (need[s.charAt(right)]-- > 0) count--;
            while (count == 0) {
                if (right - left + 1 < min) {
                    min = right - left + 1;
                    start = left;
                }
                if (++need[s.charAt(left++)] > 0) count++;
            }
        }
        return min == Integer.MAX_VALUE ? "" : s.substring(start, start + min);
    }
}
```

### 56、<a href="https://leetcode.cn/problems/merge-intervals/" target="_blank" rel="noopener noreferrer">合并区间</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]

**思路**：按左端点排序，依次与结果末尾区间尝试合并。

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        List<int[]> ans = new ArrayList<>();
        for (int[] in : intervals) {
            if (ans.isEmpty() || ans.get(ans.size() - 1)[1] < in[0]) ans.add(in);
            else ans.get(ans.size() - 1)[1] = Math.max(ans.get(ans.size() - 1)[1], in[1]);
        }
        return ans.toArray(new int[ans.size()][]);
    }
}
```

### 189、<a href="https://leetcode.cn/problems/rotate-array/" target="_blank" rel="noopener noreferrer">轮转数组</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

输入：nums = [1,2,3,4,5,6,7], k = 3

**思路**：先整体反转，再分别反转前 k 个和后 n-k 个元素。

```java
class Solution {
    public void rotate(int[] nums, int k) {
        k %= nums.length;
        reverse(nums, 0, nums.length - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, nums.length - 1);
    }
    private void reverse(int[] nums, int l, int r) {
        while (l < r) {
            int t = nums[l]; nums[l++] = nums[r]; nums[r--] = t;
        }
    }
}
```

### 238、<a href="https://leetcode.cn/problems/product-of-array-except-self/" target="_blank" rel="noopener noreferrer">除自身以外数组的乘积</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定整数数组 nums，返回每个位置除自身以外其他元素的乘积。
输入：nums = [1,2,3,4]
输出：[24,12,8,6]

**思路**：结果数组先存前缀积，再从右往左乘以后缀积。

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int[] ans = new int[nums.length];
        ans[0] = 1;
        for (int i = 1; i < nums.length; i++) ans[i] = ans[i - 1] * nums[i - 1];
        int right = 1;
        for (int i = nums.length - 1; i >= 0; i--) {
            ans[i] *= right;
            right *= nums[i];
        }
        return ans;
    }
}
```

### 41、<a href="https://leetcode.cn/problems/first-missing-positive/" target="_blank" rel="noopener noreferrer">缺失的第一个正数</a> <span class="difficulty-badge difficulty-badge--hard">困难</span>

输入：nums = [1,2,0]
输出：3

**思路**：把值 x 放到下标 x-1 的位置，最后第一个不匹配的位置就是答案。

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            while (nums[i] > 0 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {

                nums[i] = nums[idx]; nums[idx] = t;
            }
        }
        for (int i = 0; i < n; i++) if (nums[i] != i + 1) return i + 1;
        return n + 1;
    }
}
```

```java
class Solution {

        int m = matrix.length, n = matrix[0].length;
        boolean row0 = false, col0 = false;

        for (int j = 0; j < n; j++) if (matrix[0][j] == 0) row0 = true;
```

### 54、<a href="https://leetcode.cn/problems/spiral-matrix/" target="_blank" rel="noopener noreferrer">螺旋矩阵</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定 m x n 矩阵 matrix，按顺时针螺旋顺序返回所有元素。
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[1,2,3,6,9,8,7,4,5]

**思路**：维护上下左右边界，每走完一圈就收缩对应边界。

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> ans = new ArrayList<>();
        int top = 0, bottom = matrix.length - 1, left = 0, right = matrix[0].length - 1;
        while (top <= bottom && left <= right) {
            for (int j = left; j <= right; j++) ans.add(matrix[top][j]);
            top++;
            for (int i = top; i <= bottom; i++) ans.add(matrix[i][right]);
            right--;
            if (top <= bottom) for (int j = right; j >= left; j--) ans.add(matrix[bottom][j]);
            bottom--;
            if (left <= right) for (int i = bottom; i >= top; i--) ans.add(matrix[i][left]);
            left++;
        }
        return ans;
    }
}
```

```java
        }
    }
}
```

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int row = 0, col = matrix[0].length - 1;
        while (row < matrix.length && col >= 0) {
            if (matrix[row][col] == target) return true;
            if (matrix[row][col] > target) col--; else row++;
        }
        return false;
    }
}
```

### 160、<a href="https://leetcode.cn/problems/intersection-of-two-linked-lists/" target="_blank" rel="noopener noreferrer">相交链表</a> <span class="difficulty-badge difficulty-badge--easy">简单</span>

给定两个单链表头节点，返回它们相交的起始节点，不相交返回 null。

输出：Intersected at '8'

**思路**：双指针分别走 A+B 和 B+A，相遇点就是交点或 null。


```java
class Solution {
    public int orangesRotting(int[][] grid) {
        Queue<int[]> q = new ArrayDeque<>();
        int fresh = 0, minutes = 0;
        for (int i = 0; i < grid.length; i++) for (int j = 0; j < grid[0].length; j++) {
            if (grid[i][j] == 2) q.offer(new int[]{i, j});
            if (grid[i][j] == 1) fresh++;
        }
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
        while (fresh > 0 && !q.isEmpty()) {
            int size = q.size();
            minutes++;
            for (int i = 0; i < size; i++) {
                int[] cur = q.poll();
                for (int[] d : dirs) {
                    int x = cur[0] + d[0], y = cur[1] + d[1];
                    if (x >= 0 && x < grid.length && y >= 0 && y < grid[0].length && grid[x][y] == 1) {
                        grid[x][y] = 2; fresh--; q.offer(new int[]{x, y});
                    }
                }
            }
        }
        return fresh == 0 ? minutes : -1;
```

```java
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
```

```java
        List<List<String>> ans = new ArrayList<>();
```

```java
        for (int i = 1; i < nums.length; i++) {
            int a = max * nums[i], b = min * nums[i];
            max = Math.max(nums[i], Math.max(a, b));
            min = Math.min(nums[i], Math.min(a, b));
            ans = Math.max(ans, max);
        }
        return ans;
    }
}
```

### 416、<a href="https://leetcode.cn/problems/partition-equal-subset-sum/" target="_blank" rel="noopener noreferrer">分割等和子集</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定只包含正整数的数组 nums，判断能否分成两个和相等的子集。
输入：nums = [1,5,11,5]
输出：true

**思路**：转化为能否从数组中选出若干数，使和等于总和的一半。

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int num : nums) sum += num;
        if (sum % 2 == 1) return false;
        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;
        for (int num : nums) for (int j = target; j >= num; j--) dp[j] = dp[j] || dp[j - num];
        return dp[target];
    }
}
```

### 32、<a href="https://leetcode.cn/problems/longest-valid-parentheses/" target="_blank" rel="noopener noreferrer">最长有效括号</a> <span class="difficulty-badge difficulty-badge--hard">困难</span>

给定只含 '(' 和 ')' 的字符串 s，返回最长有效括号子串长度。
输入：s = ")()())"
输出：4

**思路**：栈保存未匹配下标，遇到匹配后用当前下标减栈顶计算长度。

```java
class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') stack.push(i);
            else {
                stack.pop();
                if (stack.isEmpty()) stack.push(i);
                else ans = Math.max(ans, i - stack.peek());
            }
        }
        return ans;
    }
}
```

### 62、<a href="https://leetcode.cn/problems/unique-paths/" target="_blank" rel="noopener noreferrer">不同路径</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

**思路**：dp[j] 表示当前行到达第 j 列的路径数，由上方和左方累加而来。

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        for (int i = 1; i < m; i++) for (int j = 1; j < n; j++) dp[j] += dp[j - 1];
        return dp[n - 1];
    }
}
```

### 64、<a href="https://leetcode.cn/problems/minimum-path-sum/" target="_blank" rel="noopener noreferrer">最小路径和</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定非负整数网格 grid，返回从左上到右下的最小路径和。
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7

**思路**：原地 DP，每个格子加上来自上方或左方的较小路径和。

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        for (int i = 0; i < m; i++) for (int j = 0; j < n; j++) {
            if (i == 0 && j == 0) continue;
            if (i == 0) grid[i][j] += grid[i][j - 1];
            else if (j == 0) grid[i][j] += grid[i - 1][j];
            else grid[i][j] += Math.min(grid[i - 1][j], grid[i][j - 1]);
        }
        return grid[m - 1][n - 1];
    }
}
```

### 5、<a href="https://leetcode.cn/problems/longest-palindromic-substring/" target="_blank" rel="noopener noreferrer">最长回文子串</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定字符串 s，返回其中最长的回文子串。
输入：s = "babad"
输出："bab"

**思路**：枚举每个字符作为中心，分别向两侧扩展奇偶长度回文。

```java
class Solution {
    public String longestPalindrome(String s) {
        int start = 0, end = 0;
        for (int i = 0; i < s.length(); i++) {
            int len = Math.max(expand(s, i, i), expand(s, i, i + 1));
            if (len > end - start + 1) {
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }
        return s.substring(start, end + 1);
    }
    private int expand(String s, int l, int r) {
        while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
        return r - l - 1;
    }
}
```

### 1143、<a href="https://leetcode.cn/problems/longest-common-subsequence/" target="_blank" rel="noopener noreferrer">最长公共子序列</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定两个字符串 text1 和 text2，返回它们最长公共子序列的长度。
输入：text1 = "abcde", text2 = "ace"
输出：3

**思路**：二维 DP，字符相等取左上加一，否则取上方和左方较大值。

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) for (int j = 1; j <= n; j++) {
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) dp[i][j] = dp[i - 1][j - 1] + 1;
            else dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
        }
        return dp[m][n];
    }
}
```

```java
class Solution {

        int m = word1.length(), n = word2.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 0; i <= m; i++) dp[i][0] = i;

            else dp[i][j] = Math.min(dp[i - 1][j - 1], Math.min(dp[i - 1][j], dp[i][j - 1])) + 1;
        }
        return dp[m][n];
```

### 169、<a href="https://leetcode.cn/problems/majority-element/" target="_blank" rel="noopener noreferrer">多数元素</a> <span class="difficulty-badge difficulty-badge--easy">简单</span>

输出：3

**思路**：用 Boyer-Moore 投票算法，候选人票数为 0 时更换候选人。

```java
class Solution {
    public int majorityElement(int[] nums) {
        int candidate = 0, count = 0;
        for (int num : nums) {
            if (count == 0) candidate = num;
            count += num == candidate ? 1 : -1;
        }
        return candidate;
    }
}
```

### 75、<a href="https://leetcode.cn/problems/sort-colors/" target="_blank" rel="noopener noreferrer">颜色分类</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定只含 0、1、2 的数组 nums，原地按颜色排序。
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]

**思路**：荷兰国旗三指针，0 放左边，2 放右边，1 留中间。

```java
class Solution {
    public void sortColors(int[] nums) {
        int left = 0, i = 0, right = nums.length - 1;
        while (i <= right) {
            if (nums[i] == 0) swap(nums, left++, i++);
            else if (nums[i] == 2) swap(nums, i, right--);
            else i++;
        }
    }
    private void swap(int[] nums, int i, int j) {
        int t = nums[i]; nums[i] = nums[j]; nums[j] = t;
    }
}
```

### 31、<a href="https://leetcode.cn/problems/next-permutation/" target="_blank" rel="noopener noreferrer">下一个排列</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定整数数组 nums，原地改成字典序的下一个排列，不存在则变为升序。
输入：nums = [1,2,3]
输出：[1,3,2]

**思路**：从右找第一个下降点，再从右找更大的数交换，最后反转后缀。

```java
class Solution {
    public void nextPermutation(int[] nums) {
        int i = nums.length - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        if (i >= 0) {
            int j = nums.length - 1;
            while (nums[j] <= nums[i]) j--;
            swap(nums, i, j);
        }
        reverse(nums, i + 1, nums.length - 1);
    }
    private void reverse(int[] nums, int l, int r) {
        while (l < r) swap(nums, l++, r--);
    }
    private void swap(int[] nums, int i, int j) {
        int t = nums[i]; nums[i] = nums[j]; nums[j] = t;
    }
}
```

### 287、<a href="https://leetcode.cn/problems/find-the-duplicate-number/" target="_blank" rel="noopener noreferrer">寻找重复数</a> <span class="difficulty-badge difficulty-badge--medium">中等</span>

给定包含 n+1 个整数且每个整数在 1 到 n 之间的数组 nums，找出重复的数。
输入：nums = [1,3,4,2,2]
输出：2

**思路**：把数组值看成链表指针，用快慢指针找环入口。

```java
class Solution {
    public int findDuplicate(int[] nums) {
        int slow = nums[0], fast = nums[0];
        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);
        slow = nums[0];
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }
        return slow;
    }
}
```
